How it works

Asymmetrical:
1. run the encryption file and it will prompt you to input your message
2. after a message is entered, a secret key is made and used to encrypt the message
3. the encrypted message is saved in a text file called 'encryptedFile.txt'
4. run the decryption file and it will take the encrypted file and change it back to the original message
5. the decrypted message is saved to a text file called 'decryptedFile.txt'

Symmetrical:
1. run the encryption file and it will prompt you to input your message
2. after a message is entered, a shared key is used to encrypt the message. Both python files have this same key as a variable
3. the encrypted message is saved in a text file called 'encryptedFile.txt'
4. run the decryption file and it will take the encrypted file and change it back to the original message
5. the decrypted message is saved to a text file called 'decryptedFile.txt'
